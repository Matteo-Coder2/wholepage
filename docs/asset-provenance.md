# Asset provenance dossier

Rule (from the removal forensics): a peripheral third-party asset took down an
11M-user extension with zero warning. Every visual asset in this package must be
original, with provenance recorded here BEFORE each submission.

| Asset | Origin | License |
|---|---|---|
| icons/icon{16,32,48,128,256}.png | Generated by `icons/make_icons.py` (this repo, original geometric mark: page bar + capture band) | MIT (ours) |
| Popup/result/options UI | Hand-written CSS, system font stack only (`system-ui`) — no bundled fonts, no icon fonts, no glyph libraries | MIT (ours) |
| Store screenshots (`store-assets/out/store-1..5.png`) | Generated by `store-assets/make-shots.mjs` + `stage-*.html` (this repo). All imagery is our own UI plus `store-assets/demo-page.html`, a demo article written for this purpose and captured by the real engine. No OS chrome, no third-party content, no emoji artwork. | MIT (ours) |

Prohibited forever (each item is a documented takedown vector in this category):
vendor emoji artwork (Apple/Google), OS window chrome or traffic-light mockups,
OS cursor images, stock icon fonts without a written license on file, any icon
resembling: a camera on blue, a red flame "S", a lens, a feather, brand
gradients.

Checklist per release: `grep -r` the package for image files not listed above;
view every new PNG; update this table in the same commit.
