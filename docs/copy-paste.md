## Description

WholePage captures an entire web page — everything above and below what's on screen — as one image or a multi-page PDF.

Click the icon or press Alt+Shift+P, and the page scrolls itself while the picture is assembled. Sticky menus appear once at the top instead of repeating down the image. Content that loads as you scroll is given time to appear first. Very long pages are never cut off silently — you choose between a PDF, numbered slices, or one scaled image.

You can also capture just the visible part of the page, or drag to select an area. The result can be copied to the clipboard, cropped, or saved as PNG or PDF, with a file name pattern you control.

Everything happens on your computer. There is no account, no upload, no watermark, and no tracking — the extension makes no network requests at all, and its full source code is public on GitHub.

Free, with no usage limits.

## Privacy tab — permission justifications

activeTab:

Lets the extension see the page the user explicitly captures, only at the moment they click the icon or use the keyboard shortcut.

scripting:

Injects the capture script (page measurement and scrolling) into the page being captured, and only into that page.

downloads:

Saves the finished image or PDF to the location the user chooses.

storage:

Remembers the user's settings (file name pattern, PDF quality) on their device.
